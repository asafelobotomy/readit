# Load this folder in Chrome (chrome://extensions → Load unpacked)

readit targets New Reddit (shreddit) only.
Coexists with Moderator Toolbox. Not a replacement for Old Reddit Redirect.

Do NOT load:  GitHub/readit/extension

Rebuild first if this directory is missing:

  cd ~/GitHub/readit && npm run build
